# Manual de Usuário - Projeto HighTask

## Visualização de Diagramas
- Acesse o repositório no [GitHub](https://github.com/Kanekovisks/Projeto-de-Sistemas/tree/main).
- Vá até a pasta [Documentação/Diagrama](https://github.com/Kanekovisks/Projeto-de-Sistemas/tree/main/Documenta%C3%A7%C3%A3o/Diagrama) e baixe o arquivo .asta.
- Visualização ou edição do arquivo necessitará de acesso a ferramenta [Astah](https://astah.net/products/).

Cada sprint possui um tipo de diagrama (caso de uso, classes, sequência, etc). 
O fluxo do sistema deve ser compreendido pelas relações entre componentes e papéis dos usuários.
